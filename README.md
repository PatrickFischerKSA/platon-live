# Platon · Live-Test

[Browseranwendung öffnen](https://patrickfischerksa.github.io/platon-live/)

Dieses Repository enthält ausschliesslich den exportierten Godot-Webbuild, die HTML-Leseansicht und Lizenznachweise. Das Entwicklungsrepository bleibt privat.

Rundgang oder Materiallabor starten. Für die Bewegung: Computer mit Tastatur und Maus, WASD, Esc für das Menü. Die Webfassung nutzt WebGL 2.0 und vereinfachte Lichteffekte.
